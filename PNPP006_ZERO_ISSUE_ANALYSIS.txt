The problem is DATA FILE MISMATCH:

   - But checking against BILL TRACKING LOGS (229 columns)
   - These are different data formats!

DATA FILE FORMATS:

1. DELIVERY DATA (what speed_report needs):
   - Columns: ~20-30 (ORDER ID, STATUS, POST OFFICE, TIMES, etc.)
   - Format: Delivery transaction data
   - Status codes: 110, 120, 210, 302, 306, 310, 410, etc.

2. BILL TRACKING LOGS (current file):
   - Columns: 229 (Way too many!)
   - Format: Tracking history logs
   - Status: Column position-based (UNNAMED: 4, UNNAMED: 5, etc.)
   - PNPP006: Only 1 record in first 100 rows
